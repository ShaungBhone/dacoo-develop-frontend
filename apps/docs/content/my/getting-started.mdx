# စတင်အသုံးပြုခြင်း

Dacoo သည် ဖောက်သည်စကားပြောဆိုမှုများ၊ မှတ်တမ်းများ၊ အလိုအလျောက်စနစ်များ၊ အစီရင်ခံစာများနှင့် ဘဏ္ဍာရေးကိရိယာများကို လုပ်ငန်းခွင်တစ်ခုတည်းတွင် စုစည်းပေးသည်။ ဦးစွာ လုပ်ငန်းခွင်အချက်အလက်များကို စစ်ဆေးပြီး ဖောက်သည်များကို ကိုင်တွယ်မည့် အဖွဲ့ဝင်များကို ဖိတ်ခေါ်ပါ။

## ပထမဆုံးပြင်ဆင်မှု

<Steps>
1. **Settings → Profile** တွင် ကိုယ်ရေးအချက်အလက်များကို စစ်ဆေးပါ။
2. **Settings → Team** တွင် အဖွဲ့ဝင်များကို ဖိတ်ခေါ်ပြီး ဝင်ရောက်ခွင့်ကို စစ်ဆေးပါ။
3. **Settings → Integrations** မှ ဖောက်သည်ဆက်သွယ်ရေးချန်နယ်တစ်ခု ချိတ်ဆက်ပါ။
4. **Inbox** တွင် ပထမဆုံးစကားပြောဆိုမှုကို တာဝန်ပေးပါ။
5. **Contacts** တွင် ဖောက်သည်ကို ထည့်သွင်း သို့မဟုတ် စစ်ဆေးပါ။
</Steps>

<Callout>ပြောင်းလဲမှုမလုပ်မီ မှန်ကန်သော လုပ်ငန်းခွင်ကို ရွေးထားကြောင်း စစ်ဆေးပါ။ မှတ်တမ်းနှင့် ဆက်တင်များသည် လက်ရှိရွေးထားသော လုပ်ငန်းခွင်နှင့် သက်ဆိုင်သည်။</Callout>

## နောက်တစ်ဆင့်

နေ့စဉ်စကားပြောဆိုမှုများအတွက် Inbox၊ ဖောက်သည်အချက်အလက်အတွက် Contacts နှင့် Companies၊ အလိုအလျောက်လုပ်ဆောင်မှုအတွက် Agents နှင့် Datasets၊ စွမ်းဆောင်ရည်အတွက် Reports ကို အသုံးပြုပါ။
