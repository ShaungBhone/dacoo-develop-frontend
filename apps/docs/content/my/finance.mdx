# Finance

Finance ကိရိယာများသည် workspace balance၊ card နှင့် transaction history ကို ဖော်ပြသည်။ ဝင်ရောက်ခွင့်သည် သင့် role နှင့် workspace တွင် ဖွင့်ထားသော feature များပေါ် မူတည်သည်။

## ငွေလွှဲမလုပ်မီ

Source balance၊ destination၊ currency၊ amount၊ fee နှင့် exchange rate ကို စစ်ဆေးပါ။ မတင်သွင်းမီ နောက်ဆုံး summary ကို ပြန်ဖတ်ပါ။

## Cards နှင့် Transactions
