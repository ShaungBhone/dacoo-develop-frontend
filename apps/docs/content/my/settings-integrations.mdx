# Settings နှင့် Integrations

Settings တွင် ကိုယ်ပိုင် preference နှင့် workspace configuration များ ပါဝင်သည်။ အပိုင်းအချို့ကို owner သို့မဟုတ် သက်ဆိုင်ရာ permission ရှိသူသာ အသုံးပြုနိုင်သည်။

## Channel တစ်ခု ချိတ်ဆက်ခြင်း

<Steps>
1. **Settings → Integrations** ကို ဖွင့်ပါ။
2. Provider ကို ရွေးပြီး connection flow ကို စတင်ပါ။
3. Provider တွင် sign in ဝင်ပြီး တောင်းဆိုထားသော permission များကို ခွင့်ပြုပါ။
4. Dacoo သို့ပြန်လာပြီး channel သည် connected ဖြစ်ကြောင်း စစ်ဆေးပါ။
5. ဖောက်သည်များနှင့် မသုံးမီ ထိန်းချုပ်ထားသော စမ်းသပ်စာတစ်စောင် ပို့ပါ။
</Steps>

## Security နှင့် access

Team membership ကို ပုံမှန်စစ်ဆေးပြီး မလိုအပ်တော့သော access ကို ဖယ်ရှားပါ။ မတူညီသော password ကို အသုံးပြုပြီး API credential ပေါက်ကြားနိုင်ပါက ချက်ချင်း ပြောင်းလဲပါ။

<Callout>Channel ကို disconnect လုပ်ပါက activity အသစ်များ Dacoo ထဲသို့ မဝင်တော့ပါ။ Live customer channel ကို မဖြုတ်မီ လုပ်ငန်းအပေါ် သက်ရောက်မှုကို စစ်ဆေးပါ။</Callout>
