# Reports နှင့် Usage

Reports သည် ဖောက်သည်၊ agent နှင့် finance ဆိုင်ရာ workspace activity ကို အနှစ်ချုပ်ပြသည်။ ကာလနှစ်ခုကို နှိုင်းယှဉ်သောအခါ တူညီသော date range ကို အသုံးပြုပါ။

## Usage ကို နားလည်ခြင်း

Usage စာမျက်နှာသည် လက်ရှိ workspace ၏ AI အသုံးပြုမှုကို ဖော်ပြသည်။ Generated response၊ attachment နှင့် knowledge-base file များသည် plan usage တွင် ပါဝင်နိုင်သည်။

## ပြောင်းလဲမှုကို စစ်ဆေးခြင်း

Metric တစ်ခု မမျှော်လင့်ဘဲ ပြောင်းလဲပါက ရွေးထားသော workspace နှင့် date range ကို စစ်ပြီး လတ်တလော Inbox နှင့် agent activity နှင့် နှိုင်းယှဉ်ပါ။
