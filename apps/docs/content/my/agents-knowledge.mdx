# Agents နှင့် Knowledge

Agent တစ်ခုသည် လုပ်ဆောင်ပုံလမ်းညွှန်ချက်နှင့် ရွေးထားသော knowledge source များကို ပေါင်းစပ်ထားသည်။ Agent တစ်ခုစီကို ရှင်းလင်းသော ဖောက်သည်လုပ်ငန်းတစ်ခုအတွက်သာ အာရုံစိုက်စေပါ။

## Agent တစ်ခု ပြင်ဆင်ခြင်း

<Steps>
1. Agent အသစ်ဖန်တီးပါ သို့မဟုတ် template တစ်ခုရွေးပါ။
2. တာဝန်နှင့် system instruction ကို ရှင်းလင်းစွာရေးပါ။
3. လုပ်ငန်းနှင့်သက်ဆိုင်သော guidance rule များ ထည့်ပါ။
4. Index ပြီးသော knowledge collection များ ချိတ်ပါ။
5. Opening message နှင့် team assignment ကို ပြင်ဆင်ပါ။
6. ဖောက်သည်စကားပြောဆိုမှုတွင် မသုံးမီ စမ်းသပ်ပါ။
</Steps>

## Knowledge ပြင်ဆင်ခြင်း

Dataset တွင် retrieval အတွက် Dacoo က index လုပ်မည့် document များ ပါဝင်သည်။ Document status သည် ready ဖြစ်မှ agent ဖြေကြားမှုအတွက် အားကိုးပါ။

<Callout>ရွေးထားသော knowledge တွင် အဖြေမရှိပါက agent က မရှိကြောင်း ပြောသင့်သည်။ မရှိသောအချက်အလက်ကို ခန့်မှန်းစေသည့် instruction မထည့်ပါနှင့်။</Callout>
