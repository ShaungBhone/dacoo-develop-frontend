# Inbox

Inbox သည် ချိတ်ဆက်ထားသော ချန်နယ်များမှ ဖောက်သည်စကားပြောဆိုမှုများအတွက် အဖွဲ့သုံးနေရာဖြစ်သည်။ လုပ်ဆောင်ရန်လိုသည့် စကားပြောဆိုမှုများကို filter နှင့် priority ဖြင့် ရှာဖွေပါ။

## စကားပြောဆိုမှုကို ကိုင်တွယ်ခြင်း

<Steps>
1. စာရင်းမှ စကားပြောဆိုမှုတစ်ခုကို ရွေးပါ။
2. မဖြေမီ ဖောက်သည်အချက်အလက်နှင့် ယခင်စာများကို ဖတ်ပါ။
3. မိမိ၊ အဖွဲ့ဝင် သို့မဟုတ် AI agent တစ်ခုထံ တာဝန်ပေးပါ။
4. စာပြန်ရေးပါ သို့မဟုတ် saved reply ကို ထည့်ပြီး မပို့မီ ပြန်စစ်ပါ။
5. နောက်တစ်ယောက် နားလည်လွယ်ရန် tag နှင့် priority ကို သတ်မှတ်ပါ။
</Steps>

## လူနှင့် AI အကြား လွှဲပြောင်းခြင်း

AI agent သည် သတ်မှတ်ထားသော လမ်းညွှန်ချက်နှင့် knowledge ကို အသုံးပြု၍ ဖြေကြားသည်။ လူသားဆုံးဖြတ်ချက် သို့မဟုတ် သတိထားကိုင်တွယ်မှု လိုအပ်ပါက အဖွဲ့ဝင်တစ်ယောက်ထံ ပြန်လည်တာဝန်ပေးပါ။
