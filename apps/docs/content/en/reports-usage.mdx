# Reports and usage

Reports summarize workspace activity across customers, agents, and finance. Use the date controls consistently when comparing periods.

## Understand usage

The Usage page tracks AI consumption for the active workspace. Generated responses, attachments, and knowledge-base files can contribute to plan usage.

## Investigate changes

When a metric changes unexpectedly, confirm the selected workspace and date range, then compare it with recent Inbox and agent activity.

<Callout>Usage and billing views may update at different times. Treat very recent activity as provisional until processing finishes.</Callout>
