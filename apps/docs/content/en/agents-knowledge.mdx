# Agents and knowledge

An agent combines behavior instructions with selected knowledge sources. Keep each agent focused on a clear customer job and give it only the information required for that job.

## Configure an agent

<Steps>
1. Create an agent or select a starter template.
2. Write a clear role and system instruction.
3. Add guidance rules for business-specific behavior.
4. Attach indexed knowledge collections.
5. Configure its opening message and team assignment.
6. Test the agent before assigning live conversations.
</Steps>

## Prepare knowledge

Datasets contain documents that Dacoo indexes for retrieval. Wait until a document shows as ready before relying on it in agent answers.

<Callout>Agents should say when the selected knowledge does not contain an answer. Avoid instructions that encourage guessing outside the available sources.</Callout>
