# Settings and integrations

Settings contains personal preferences and workspace-level configuration. Some sections are available only to owners or members with the required permission.

## Connect a channel

<Steps>
1. Open **Settings → Integrations**.
2. Choose the provider and start the connection flow.
3. Sign in to the provider and grant only the requested permissions.
4. Return to Dacoo and confirm that the channel reports as connected.
5. Send a controlled test before using it with customers.
</Steps>

## Security and access

Review team membership regularly, remove access that is no longer needed, and use a unique password. Rotate API credentials immediately if they may have been exposed.

<Callout>Disconnecting a channel stops new activity from entering Dacoo. Confirm the operational impact before disconnecting a live customer channel.</Callout>
